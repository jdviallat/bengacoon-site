# Bengacoon — site officiel de l'application

Page de présentation publique de l'application **Bengacoon** — gestion d'un cabinet de
thérapie et de communication animale (Android).

👉 **https://jdviallat.github.io/bengacoon-app-site/**

- `index.html` — page d'accueil
- `privacy.html` — politique de confidentialité (URL à déclarer dans Play Console)
- `assets/` — icône

Code source privé : [jdviallat/bengacoon](https://github.com/jdviallat/bengacoon). Ce dépôt public porte la page, la politique de confidentialité, `latest.json` (lu par l'app pour se mettre à jour) et les APK en Releases.

> À ne pas confondre avec le **site internet** de l'activité Bengacoon (WordPress).
